# Design System

## Design Principles
- **Premium Feel**: Utilize ample whitespace, balanced proportions, and sophisticated motion to convey high quality.
- **Dynamic Interaction**: Ensure the page responds smoothly to user inputs (scroll, load), avoiding abrupt changes.
- **Clarity**: Typography and metrics must be legible despite underlying animations.

## Color Palette
- **Background**: Deep, rich dark colors or stark, crisp whites depending on the theme (e.g., #0F0F0F for dark mode).
- **Text Primary**: High contrast color (e.g., #FAFAFA on dark background).
- **Accent/Highlight**: A vibrant, energetic color for the primary visual element and key statistics (e.g., #FF4C29 or #00D2FF).

## Typography
- **Primary Font**: A modern, clean sans-serif (e.g., Inter, Roboto, or Space Grotesk for a slightly technical look).
- **Headline**: "W E L C O M E I T Z F I Z Z"
  - Large font size.
  - Generous letter spacing (e.g., `tracking-[0.5em]`).
  - Uppercase.

## UI Components
1. **Hero Headline**: Center-aligned, dynamically animated into view.
2. **Statistics/Metrics Block**: Small, easily digestible numeric stats with brief labels, staggered during load.
3. **Scroll Visualizer**: The main interactive element (e.g., a car graphic) that traverses or scales according to scroll depth.
